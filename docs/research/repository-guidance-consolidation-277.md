### Repair-policy authority

single comprehensive repair-policy authority. Selected verification, placement,
activation, native-goal feedback and lifecycle correction now refer to it instead
of restating policy. The following map covers every removed or moved clause;
source locations refer to the initial consolidation candidate.

Ordered invariant identifiers and fenced protocol blocks remain byte-identical
to the original issue baseline in all three specifications. Code-review and
skill-evaluation evaluation-requirement suffixes remain byte-identical too.
Adaptive Goal's suffix changes only within ADL-A4, which incorporates the clauses
above; its other evaluation-obligation text remains byte-identical. The former
whole-suffix equality audit therefore no longer applies to Adaptive Goal.
Clause mapping and semantic comparison establish preservation for the changed
ADL-A4 text; unchanged-text hashes alone do not establish that conclusion.

Evaluation requirements remain evidence obligations rather than second behavior
definitions. Every existing evaluation requirement is retained: Adaptive Goal's
transport/comparison, fixture, adaptation and outcome obligations; skill
evaluation's 22 numbered requirements; and code review's CR-E1–CR-E19. Their
scenario matrices, host conditions, exceptions, grading rules and protocol fields
are unchanged. No acceptance assertion was weakened to make this cleanup pass.
