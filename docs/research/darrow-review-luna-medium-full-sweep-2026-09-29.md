## What the failures share

Several failures occur at the coordinator's boundaries: reading caller input, launching isolated readers, copying the canonical output, and returning to an enclosing goal. Correct findings and clear verification often reached validated artifacts before the final handoff failed. These warrant work at the shared input and output boundaries across both review modes.

The two goal-completion fixtures are independently invalid: participant-facing `mark-complete.sh` calls `.git/eval-checks/review/tests/evals/assert_records.py`, while the runner intentionally denies participant access to `.git/eval-checks`. Seven responses explicitly reported the access error; three returned only the capability report, so their exact completion-script attempts remain unverified. Their raw 0/5 results are preserved. Repair these fixtures before using them to judge owner continuation.

The machine-output failure is different from a lost finding or criterion. Its validated JSON fields, rendered with the same backend and report path, reproduced the independently captured canonical Markdown SHA256. The observed key order differs from the finalizer. CR-C15 requires validated JSON; the eval's byte comparison and the skill's stronger verbatim-copy instruction need alignment. The original JSON bytes were not retained, so the directly established equivalence is the complete rendered semantic report.

Both activation failures passed every task check. Native diagnostics showed recognized parent compound `cat` attempts without a complete body, frontmatter or a bound native skill path. No complete read was recovered. The required activation evidence failed; these facts do not independently prove intent misses or observer defects. Inspect their shared read and output format first.

## Recommended next steps

1. Repair the two public completion scripts and calibrate the initial-review summary assertion against the requested outcome. Keep hidden grading inaccessible and rerun the affected cases.
2. Align machine-output instructions and assertions around equality of the validated JSON data, preserving all values and rejecting added prose. Calibrate with reordered-identical and changed-data records.
3. Investigate shared input binding, prepared-reader dispatch and final report delivery. Capture bounded path/type facts and hashes across the relevant boundaries before deciding which layer owns an ambiguous failure.
4. Inspect the unverified skill read and reported delegation prohibition separately. Establish the exact installed path and effective host authority; preserve blocking when delegation is genuinely prohibited.

No recorded failure identifies missing legacy guidance as its cause. The modern finding-format contract remains intact. Earlier audit findings about omitted external-handoff history and regression-only state transfer remain open; a green second-round fixture does not close those different states.
