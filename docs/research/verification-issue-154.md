# Verification capability delivery evidence

This record describes bounded local observations for issue #154 on 2026-09-13.
It does not establish model stability or change the normative verification
contract. The acceptance requests were written before the skill instructions.

## Scope and method

The capability composes the current public review capability and an independently
mounted, differently named replacement skill. A narrow portable Bash renderer
preserves the authored assessment and appends a validated absolute report link.
It does not interpret provider reports, decide findings or write product files.
The replacement fixture is inert Markdown in source; only isolated trial
repositories materialize it as a host-advertised skill. Neither production
verification instructions nor its reference imports another plugin's files.

Each live case used one trial, one job and an 80% configured threshold. A 1/1
pass is an observation, not a reliability estimate. Codex used CLI 0.154.0 with
gpt-5.6-terra/medium; Claude Code used CLI 2.1.223 with
claude-sonnet-5/medium. Semantic checks used gpt-5.6-luna/low. The existing review
provider selected fresh Codex gpt-5.6-sol/xhigh readers and Claude Opus 5/xhigh
readers through its own public routing mechanics. Replacement readers were
checked for native fresh-context execution without claiming a pinned model.
Some Codex child-inclusive token totals are unknown. Per-trial measurements stay
in the source JSON; unavailable totals are not treated as zero.

The final no-progress Claude observation used `claude-opus-5/high` after the
Sonnet/medium coordinator repeated repair advice and, in one run, invoked the
provider inline without the required separate provider context. Opus/high
passed that case with separate fresh contexts and a stop reason without another
repair instruction. This is route-specific evidence, not proof of a causal
model improvement or a passing Sonnet/medium no-progress result. The evidence
manifest preserves each trial's actual route and the earlier failures.

Live diagnosis was sequential and stopped at the first failed case. Dry
preparation, activation, task outcomes, invariant coverage and ablation are
separate evidence. Checks inspect candidate preservation, complete provider
report references, canonical existing-provider result validation, native reader
events and semantic criterion/conclusion behavior. Optional QA and presentation
providers are absent unless a case explicitly requires an unsupported one.
