# Capability specifications

These files define current invariants. Start with the
[documentation hub](../README.md) for user tasks, or follow a contract below.

- [Repository guide](repository-guide.md): grounded read-only explanation and migration.
- [Layer composition](layer-composition.md): responsibilities and handoffs.
- [Information architecture](information-architecture.md): repository agent guidance.
- [Decision management](decision-management.md): authority and lifecycle.
- [Skill authoring](skill-authoring.md): focused, discoverable skills.
- [Git workflows](git-workflow.md): branches, commits, and PR authority.
- [Ticket management](ticket-management.md): provider operations.
- [Implementation readiness](implementation-readiness.md): sufficient intent and evidence.
- [Discovery](discovery.md): grilling, discovery, and planning.
- [Visual explanation](visual-explanation.md): compact grounded views.
- [Test-driven development](test-driven-development.md): red/green evidence.
- [Code review](code-review.md): independent review and repair verification.
- [Verification](verification.md): replaceable assessment and criterion-level evidence.
- [Langfuse observability](observability-langfuse.md): Codex telemetry and privacy.
- [Repository Python quality](python-quality.md): package inventory, checks, tests, and release evidence.
- [Marketplace installation](marketplace-installation.md): inventory-driven host installation shortcuts.
- [Adaptive Delivery](adaptive-delivery.md): one explicit execution owner.
- [Ticket to PR](ticket-to-pr.md): the delivery recipe.
- [Ticket pipeline](ticket-pipeline.md): the static reference.
- [Skill evaluation](skill-evaluation.md): native behavior, activation, and comparison.

[Accepted decisions](../decisions/README.md) explain settled choices.
[Research](../research/README.md) is context and does not override these contracts.
