# Pstack curated bundle

`darrow-pstack` packages Lauren Tan's `unslop`, the 24 selected Darrow principle
adaptations, `principles-first`, and `setup-principles`. Both Codex and Claude
Code entrypoints expose the same 27 skills from one independently installable
plugin. No sibling plugin files or additional registry are required.
