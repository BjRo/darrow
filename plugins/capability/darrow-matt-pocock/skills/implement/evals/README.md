# Implement recipe checks

`missing-owner.yaml` installs only Matt and checks that missing Adaptive Goal
leaves the requested file and history unchanged. `approved-local.yaml` and its
Claude variant install Matt, Adaptive Goal and pstack without a Git plugin.
They require the shell CLI behavior, a scoped local Conventional Commit,
candidate-bound independent reader results and no external publication.
Commits use native Git under repository instructions.

The Review fixture is a compatible public provider. Its workflow launches fresh
Standards and Acceptance readers. Real Darrow Review composition belongs to the
Adaptive Goal/Review suites. These cases use a disposable local bare remote.

Run `bun test ./evals/domain/implement-recipe-fixture.test.ts` for fixture,
public preparation and oracle checks, including prohibited effects. These
checks do not establish native model behavior. Live runs must retain host,
model, effort, trial count, threshold, activation and task outcomes separately.
Historical runs of the removed commit-provider contract do not validate the
current native Git behavior.
