# PR presentation credits

Darrow's `create-pr` adapts the Summary, Evidence, and Merge Danger approach
from [Matt Pocock's PR skill](https://github.com/mattpocock/skills/blob/abeeaf95660ba9e8b7c753eb38f441ca707a8823/skills/engineering/pr/SKILL.md),
inspected at revision `abeeaf95660ba9e8b7c753eb38f441ca707a8823`.
Its [upstream credits](https://github.com/mattpocock/skills/blob/abeeaf95660ba9e8b7c753eb38f441ca707a8823/skills/engineering/pr/CREDITS.md)
attribute the smallest-useful-view approach, visual choices, and adjacent
placement guidance to Dexter (Dex) Horthy and HumanLayer's `show-me` skill.

The [show-me source](https://github.com/humanlayer/skills/blob/4d69d20f6e9b57b4fcf0d501ccfb1be961f0f329/plugins/show-me/skills/show-me/SKILL.md)
and [HumanLayer MIT notice](https://github.com/humanlayer/skills/blob/4d69d20f6e9b57b4fcf0d501ccfb1be961f0f329/LICENSE)
were inspected at revision `4d69d20f6e9b57b4fcf0d501ccfb1be961f0f329`.
Matt's credits do not pin the historical show-me revision; this inspected
revision is a provenance reference, not a claim about that earlier copy.

Acquisition: direct HTTPS reads of the exact GitHub revision paths above and
[Matt's MIT notice](https://github.com/mattpocock/skills/blob/abeeaf95660ba9e8b7c753eb38f441ca707a8823/LICENSE)
on 2026-11-20. No upstream publisher, skill directory, or runtime dependency was
imported. Updates are deliberate and demand-driven; compare these pinned
sources and preserve the applicable notices when adapting future changes.

Darrow rewrites the presentation guidance to honor repository templates, allow
short prose, distinguish observed evidence from unknowns, and qualify rollback
and consumer-impact claims. Existing Git publication mechanics and authority
remain Darrow's. Neither the Matt PR skill nor show-me is required at runtime.
The borrowed material retains its MIT terms below; the rest of Darrow Git
remains under its [existing license](../../LICENSE).
