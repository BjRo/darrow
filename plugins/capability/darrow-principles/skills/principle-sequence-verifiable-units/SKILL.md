# Apply sequence verifiable units

Establish a baseline, then divide dependent sweeps, migrations or multistep
changes into coherent units that can be checked. Complete and check the
current unit before advancing.

Agreed migration phases and red/green development may contain expected
intermediate failures inside a unit. Judge advancement by that unit's agreed
checks and preserve final acceptance requirements.

Sequencing grants no rebase, commit, history rewriting or publication
authority. Existing ownership, repair and stop conditions still govern.

Complete when: each completed unit has its required evidence and the next
unit depends only on a checked baseline.
