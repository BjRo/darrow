# Apply guard the context window

Use narrow, bounded reads for large files, outputs and investigations. Avoid
repeating already sufficient reads, and retain the material constraints,
decisions and evidence needed for the next step.

Choose more context or a different read when it resolves a concrete uncertainty.
Delegation is optional, not a requirement of context management. The task's
owner and host permissions govern whether and how work may be delegated.

Complete when: the next decision has its necessary evidence without losing
material constraints or spending context on unrelated output.
