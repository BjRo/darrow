# Apply explain the number

Define the metric and the decision it informs before measuring. Verify the
intended work actually ran, compare equivalent conditions, account for
variation, and retain the evidence behind the claim.

For performance, identify the limiting factor rather than reporting an
unexplained timing. For evals, use valid trials and independent checks that
measure the claimed outcome. Explain what the measurement can and cannot
establish; no particular tool or fixed trial count is mandatory.

Complete when: the number has a defined meaning, comparable evidence and an
honest relationship to the decision being made.
