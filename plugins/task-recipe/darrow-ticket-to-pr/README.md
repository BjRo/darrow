# Darrow Ticket to PR

`ticket-to-pr` is an explicitly invoked task recipe for turning one ready,
authoritative ticket in the current repository into exactly one verified pull
request. It preserves the active provider's opaque ticket token in any derived
branch, and owns ticket intake, readiness interaction, and the bounded branch,
commit, non-force push, and pull-request authority envelope. A compatible
adaptive native-goal capability owns execution, verification, feedback, and
completion.

The recipe never creates a controller, retry runtime, ledger, status file,
worktree, merge, release, deployment, or ticket mutation.
