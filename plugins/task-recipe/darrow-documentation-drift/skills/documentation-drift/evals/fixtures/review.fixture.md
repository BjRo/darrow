# Independent draft review fixture

This controlled fixture substitutes the provider boundary for independent
judgment. Report this limitation; it does not execute fresh independent readers.
Resolve the normalized absolute path of `.fixture-bin/review-draft` from the
fixture repository, then invoke that literal path with the exact absolute draft
path. Return its decision unchanged. A finding requires a revised draft and
another invocation for closed repair verification. Rejection withholds that
finding. The helper records content identities so stale clearance cannot pass.
