# Native Principles delivery fixture

This private native plugin advertises the scoped provider test doubles used by
Principles delivery evals. The isolated eval installs their commands. The
package is excluded from the marketplace and has no hooks or backend.

The full Principles, Adaptive Goal, TDD, Verification and Review plugins remain
real. These bodies model incidental readiness, existing-branch reuse, scoped
commit, ticket, publication and CI interfaces. Their effects are limited to
isolated fixture repositories and local mock forge state. Required fresh-reader,
current-candidate, TDD and final CI checks remain unchanged.

## Source entrypoint exception

Fixture skills normally remain inert templates in source, as required by the
eval development guide. These `SKILL.md` files are an intentional narrow
exception: the existing native-plugin resolver requires real skill entrypoints
beneath a three-part repository plugin path. Project-skill fixtures conflict
with Claude's isolated native-goal hooks. The native fixture plugin preserves
those hooks and registration without changing the generic runner or limits.

The package stays under `plugins/fixtures`, outside both canonical agent skill
roots. Its descriptions restrict use to these evals, and a deterministic guard
keeps it out of the marketplace. It is advertised to an eval session only when
that case explicitly mounts it through `additional_plugins`. Tests keep the
native profile's hook isolation and read-only review-artifact grants.

After fixture changes, validate public preparation and both native-host composed
cases with the documented review-artifact runtime profile. Do not enable
project settings or substitute direct shell calls for unavailable providers.

The composed cases select only the six delivery providers through
`additional_skills`. The compatible-approach recipe case selects only the
separate `thoughtful-engineering` provider, so it cannot compete with the real
Principles entry in composed delivery. Both selections retain native plugin
packaging and explicit fixture command prerequisites.
