# Acceptance and bounded repairs

The main thread owns criterion coverage, combined conclusions, history and repair
accounting, including when Review is omitted. Review owns fresh independent
judgments and its public workflow, placement and readers. Standalone Verification
is not required.

## Assess current content

Pass required checks before selected assessments or dependent effects. For
assessment-before-change intent, check and assess the unchanged candidate first.
Failed checks require authorized repair and refreshed evidence or a stop.

Invoke each selected provider's full public workflow with repository,
base/scope/current content identity, objective, all material criteria, constraints
and successful current checks. Require fresh independent standards/acceptance
judgments as applicable, preserved findings/dispositions/closed history and
missing/stale evidence kept unavailable. Inline role switching or inherited
author context cannot supply independent judgment. Follow the provider's routes
and reader controls without private-mechanics access or substitute readers.
Wait for every result before editing.

Map each criterion to its source, current target and supporting check/independent
evidence, supported failure or explicit gap. Read actual current check assertions;
retain exact commands/results. Shape checks prove no values. Missing staging or
deployment observations remain unavailable. Unassessed criteria are gaps, not
invented review findings; keep blockers and advisories distinct.

Bind returned identities to current content. Different identity schemes/scopes
need an observed relationship; unsupported relationships are gaps, not invented
mismatches. Refresh invalidated checks and every selected assessment after edits.
An unavailable selected provider supplied no assessment.

Retain provider-native outcomes separately from the combined conclusion:

| Conclusion    | Meaning                                                                                                                                            |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `clear`       | Every criterion has current evidence, required checks pass, no eligible blocker/direct regression remains                                          |
| `progress`    | Initial actionable evidenced defects; on follow-up, material improvement or a new direct repair-caused regression eligible for owner consideration |
| `no-progress` | Follow-up failure is unchanged, repeated or oscillating                                                                                            |
| `blocked`     | Required input, provider, check, result, criterion coverage or conclusive evidence is missing/unavailable                                          |

Gaps take precedence, then no-progress, then progress. Advisories remain visible
and nonblocking. A pass or zero exit status alone proves no acceptance. Require
clear acceptance before final commits, publication and completion; explicitly
bound intermediate worker commits retain their focused-check exception.

Keep and read complete provider results and supplied absolute report references.
A promised missing report is an incomplete handoff: do not search storage or
guess paths. Compatible inline-only providers need no invented artifacts.

## Preserve closed history

Retain objective, criteria, constraints, base/scope, original/prior/current target
identities, attempted repairs and changed-content evidence. Preserve every
original finding's identity, provider/axis, severity, disposition, location,
source/evidence; all follow-up results; and direct regressions linked immutably
to their causing original findings. Mark the first follow-up explicitly. Missing
or contradictory history blocks follow-up.

Send original/prior results unchanged, the explicit attempted set, current repair
scope and successful checks through the same provider's public repair-verification
workflow. Preserve opaque references without private-record parsing or fabricated
artifacts. Keep the original set closed except for evidenced direct repair-caused
regressions. Unrelated observations extend neither scope nor allowance.
Unattempted blockers stay unresolved; advisories stay nonblocking.

Retain each independent state: resolved, improved but unresolved, unchanged or
unavailable. Unsupported regression causality is a gap. Repeated/oscillating
evidence is no-progress. The final summary preserves original identities, axes,
dispositions, current states, causing-original links, criterion coverage and
reports; links alone cannot replace those facts. Exclude author conclusions
from fresh reader inputs.

## Decide repairs

The default maximum is **2 repair attempts total**, shared across providers and
findings. Only an explicit finite user/repository override changes it. Progress,
"keep trying", a singular repair request or finding count cannot raise it.
Honor stricter invocation, time, token and authority limits. Unknown counts stop
repair. Apply the first matching row and give the decision before advice:

| Condition                                                      | Action                                                                                                                                  |
| -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Combined result clear, every criterion supported               | Stop repairing; unused attempts need not be used                                                                                        |
| Attempts used at least the maximum, or another limit exhausted | Stop                                                                                                                                    |
| Required evidence missing/unavailable/inconclusive             | Stop speculative repair; investigate within existing authority or obtain the environment decision                                       |
| Latest repair made no progress                                 | Stop repairing; report the blocker, investigate only within existing authority                                                          |
| Authorized in-scope blocker, evidenced action, attempts remain | One combined repair, refreshed checks and closed follow-up; after a prior repair require provider-observed resolution or narrowed cause |

Authorize both the attempt and subsequent assessment. No-progress advice states
the stop reason without an edit-and-reverify recipe. Route one combined repair
to the producing implementor under section 7. Splitting or replacement never
resets/multiplies attempts. Stay within original scope; stronger checks of the
same behavior are permitted. Pass invalidated checks and obtain closed follow-up
before the next decision.

For a demonstrated invocation error or concrete new evidence, request one bounded
correction from the same provider. Compare the actual command/path/diagnostic
with its loaded contract. Preserve every earlier result and obtain fresh judgment
explaining supersession. Never edit provider artifacts, retry unchanged refusals
or restart comprehensive review. Correction consumes/resets no implementation
attempt; unverified causes remain gaps.

Missing authority, blocked/inconclusive evidence, no progress or exhausted limits
stop repair, completion and remaining publication. Report the combined conclusion,
criterion evidence/gaps, preserved findings and attempts used/maximum/source.
