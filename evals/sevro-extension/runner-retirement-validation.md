# Generic runner retirement

The published exact pin and default caller switch precede this removal.
The [scoped release record](scoped-release-validation.md) retains the installed
comparison, full installed coverage, and targeted expectation repair. The
[caller record](default-package-validation.md) retains all three test-first
switches and the complete 40-test public caller gate.

The 57 inventoried legacy implementation, private unit test, and source-copy
baseline files are removed. The temporary `parity/sevro.test.ts` comparison is
also retired after its observed comparisons and deliberate migrations. Its
private adapter imports, generated legacy launcher, and source-copy installation
cannot remain an installed integration mechanism.

The runner tree now contains only five thin commands and eleven public
integration test files. Darrow's 24 domain test files, cases, suites, conditions,
corpus definitions, snapshots, and plugin assets remain. Generic engine, host,
grader, lifecycle, isolation, and reporting coverage belongs to Sevro's own
245-test suite. No generic source or private types are imported by the remaining
Darrow integration. The retained public CLI and protocol checks do not copy the
retired implementation.

`test:eval-runner-compatibility` now runs the public integration and domain gate
against the installed dependency. The old `DARROW_EVAL_RUNNER_COMMAND` launcher
contract is retired. Archive interpretation remains in Darrow's independent
report, comparison, ablation, and reviewer-routing readers. Legacy phase,
profile/workflow/risk, fixed completion prose, and guard expectations retain
their documented dispositions; no deprecated pipeline instrumentation or active
benchmark correction is added.

After removal, typecheck and the documentation check passed. A source import
scan found no retired private runner references or Sevro engine/host imports.
The existing public suite regression passed without route overrides: one test /
49 assertions in 6.28 seconds, covering four selected passive and enforced
adapter cells, their separate reports, provenance, and outcomes. Those adapter
cells do not establish bundled-host enforced execution.

The previous 74-file inventory and accepted domain dispositions remain in the
[ownership record](runner-cutover-inventory.md). Automatic frozen installed CI,
the final full installed gate, and focused native validation remain required.
